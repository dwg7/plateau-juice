# ADR 0003: urf空間結合による属性充実率の検証

- 日付: 2026-10-01
- ステータス: 確定(結果)/ 解釈は未検証(`notes/findings.md` F2)
- 再現: `scripts/urf-join.py` → `scripts/verify-urf.py`。結果表は `notes/urf-verification.md`

## 手法
建物の重心(lat/lon)を、`udx/urf` の都市計画区域(1ポリゴン)・区域区分(105)・用途地域(1,614)と点-in-ポリゴンで結合する
(shapely STRtree)。ポリゴンは結合の計算にだけ使い、出力は区域コードの列(`urban_planning_area`、`area_class`、`urf_zone`)のみ。

## 結果
- 市街化区域の属性あり率64.2%、調整区域0.9%。ただし属性なし棟の86%は市街化区域内にある
- 市街化区域内の欠損は、高さ約5m以下の建物、普通無壁舎、クラス不明の棟に集中
- `zone_type` と用途地域ポリゴンは97.3%一致。不一致は少数のタイルに集中(F2)

## 決定
- 分析母集団は、引き続き `attr_surveyed=True` とする(D9)。ただし「市街化区域内でも小規模建物は含まれない」ことを、結果の解釈に明記する
- `zone_type` と `urf_zone` の不一致棟は、「公式との不一致」の第一候補として別途保持し、札幌の土地勘による確認後に解釈を決める
- 区域区分は、属性欠損の一次的な説明変数とはせず、補助的な属性(`area_class`)として使う
